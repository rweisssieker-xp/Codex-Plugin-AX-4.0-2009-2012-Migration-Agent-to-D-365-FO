# Contributing

1. Never commit customer data, credentials, secrets, production exports or tenant-specific metadata.
2. Keep generators `REVIEW_ONLY` unless a user explicitly configures and approves an external connector.
3. Add or update a test for changed generator behavior.
4. Run unit tests, formatting and plugin validation before opening a pull request.
5. Keep target D365 claims evidence-labelled; do not assert compilation, standard fit or deployment without real evidence.
